# 국내 상장 ETF 그룹 비교

국내 상장 ETF 전 종목을 «비슷한 것끼리» 자동으로 묶어 나란히 비교하는 정적 대시보드입니다.

**보기 → https://dreamsowoon.github.io/kr-etf-compare/**

- 그룹키 = `지역 · 자산군 · 섹터 · 전략` (예: 국내·주식·코스피200·커버드콜)
- 비교 항목: 시총 · 거래대금 · 총보수 · 분배율(TTM) · 연 분배횟수 · 1M/3M/1년 · 1년 총수익 · 괴리율 · 기초지수
- 그룹 안에서 최고/최저 자동 강조, 원금잠식 의심·거래 한산 경고

## 데이터
- 시세·시총: FinanceDataReader
- 총보수·분배율·기초지수·구성종목: 네이버금융

페이지 상단의 **「데이터 MM-DD HH:MM」** 이 기준 시각입니다. 평일 15:35(KST)에 갱신해 올립니다.

## 면책
개인 참고용입니다. 「1년 총수익%」는 «1년 가격 + 분배율»로 계산한 근사치이며 정확한 분배금 재투자 복리가 아닙니다.
투자 판단 전에 각 운용사 공시를 확인하십시오.
